# 编译说明

在这个目录里跑这四行就行（MinGW 的 `g++`）：

```
g++ -std=c++17 -O2 -municode -static -o screenshot.exe screenshot.cpp -lgdiplus -lgdi32 -luser32
g++ -std=c++17 -O2 -municode -static -o mousepos.exe  mousepos.cpp  -lgdi32 -luser32
g++ -std=c++17 -O2 -municode -static -o move.exe      move.cpp      -lgdi32 -luser32
g++ -std=c++17 -O2 -municode -static -o click.exe     click.cpp     -lgdi32 -luser32
```

跑完四个 exe 就在同一层。

---

## 参数逐个看

| 参数 | 作用 |
|---|---|
| `-std=c++17` | C++ 标准 |
| `-O2` | 优化 |
| `-municode` | 入口点用 `wmain`，argv 是宽字符 → 中文路径不乱码 |
| `-static` | 不依赖 libstdc++ / libgcc 的 DLL，单文件 exe |
| `-o screenshot.exe` | 输出文件名 |
| `-lgdiplus` | GDI+（存 PNG 用）—— 只有 screenshot 需要 |
| `-lgdi32 -luser32` | GDI 和 user32（截图、光标、输入） |

- **不需要 MSVC，不需要 Windows SDK** —— MinGW 自带 Windows 头文件和导入库
- 需要mingw的`g++`
- 以后加新工具，照抄一行改文件名即可

## 为什么没有 manifest

DPI 感知是在 `wmain` 第一行用 `SetProcessDpiAwarenessContext` 打开的，
所以**不需要** `.rc` / manifest / `windres` —— 少一个文件、少一个工具。
